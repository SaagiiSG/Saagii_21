# Saagii_21 — portfolio

Personal portfolio of Saran-Ochir S. Built with React 18, Vite, Tailwind CSS 3, Framer Motion 11, and react-three-fiber.

Ink-and-paper design language: warm paper white, sumi ink black, one vermillion (hanko red) accent. Scroll-driven SVG animations — self-drawing ensō circles, brush-stroke dividers, drawn underlines — plus a scroll-rotating 3D origami crane.

## Develop

```bash
npm install
npm run dev      # dev server
npm run build    # production build → dist/
npm run deploy   # publish dist/ to GitHub Pages
```
